# BookShelf — Proyecto Final (Facultativa 1)

## Descripción
Aplicación web para gestionar libros personales. Implementada con HTML, CSS y JavaScript (Vanilla).

## Uso
1. Abrir `index.html`.
2. Ir a "Agregar" para crear un libro.
3. Buscar o filtrar desde la página principal.

## Tecnologías
- HTML5, CSS3, JavaScript (ES6)
- localStorage

## Publicación
Se puede publicar en GitHub Pages (ver instrucciones en la entrega). Para publicar:
1. Crear un repositorio en GitHub.
2. Subir los archivos.
3. Habilitar Pages en Settings → Pages → Branch: main, Folder: / (root).
