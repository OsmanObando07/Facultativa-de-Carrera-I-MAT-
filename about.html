Documentación técnica breve

Nombre: BookShelf — gestor de libros personal

Tecnologías: HTML5, CSS3, JavaScript (Vanilla), localStorage.

Requerimientos

  • Navegador moderno.
  • Conexión para la URL de portada (opcional).

Decisiones y reflexiones

Se eligió localStorage para mantener la entrega simple y cumplir el requisito de persistencia sin backend. Para producción se recomienda un backend con base de datos y autenticación.

Pruebas realizadas

  1. Agregar libro y verificar que aparece en la lista.
  2. Marcar favorito y recargar — permanece marcado.
  3. Buscar por título/autor y filtrar por categoría.
  4. Eliminar libro y comprobar que desaparece.
